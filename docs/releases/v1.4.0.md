The first Senza release you can download and run without cloning the repo, plus a full pass over
reliability, the in-game HUD and the launcher.

## Install

Download `Senza-1.4.0-macOS-arm64.dmg` below and drag Senza to Applications. Senza is ad-hoc signed, not notarized,
so allow it once in **System Settings › Privacy & Security › Open Anyway** (or
`xattr -dr com.apple.quarantine /Applications/Senza.app`). Apple Silicon, macOS 13+, Python 3.9+ (the Xcode
Command Line Tools one is enough). Checksums are in `SHA256SUMS.txt`.

## New

- **Self-contained app.** Prebuilt DualSense bridges, the `senza` CLI and profiles ship inside Senza.app. A setup
  checklist on first launch shows what's missing and fixes what it can.
- **Per-network profiles.** Senza recognises the network you're on by its router (no Location permission) and loads
  the settings you saved for it: bypass, Wi-Fi fix, stream preset.
- **Connection history.** Every check and session is recorded per network. The launcher charts this network's
  latency, and the auto stream preset uses its history instead of one lucky probe.
- **Mid-game connection warning.** When loss or jitter stays bad, the HUD tells you and suggests a lower resolution.
- **Input latency.** Senza measures key and trackpad to virtual DualSense report latency for every session
  (`senza history`).
- **Passwordless helper (optional).** `senza helper install` asks for your password once; sessions stop asking.
  It only accepts a fixed list of operations.
- **Tunnel.** Notifications when the whole-Mac tunnel switches between Tailscale and WARP, and the fastest of several
  exit nodes is picked automatically (`senza config set exit-nodes a,b`).
- **Profiles.** `senza profile new | import | export | remove`; your profiles live in `~/.config/senza/profiles`.
- **Client updates.** `senza setup --install-watch` re-prepares PS Remote Play right after an App Store update.

## Redesigned

- **In-game HUD.** One quiet style for the panel, prompt bar, toasts and ping pill. Mac keys are drawn as keycaps,
  PS buttons as their real glyphs, and colour is only used where it means something.
- **Launcher.** Rebuilt around the network you're on and its latency, with grouped session settings and a controls
  sheet. The sensitivity and key studio follows the same style.

## Fixed

- The Wi-Fi (AWDL) lag fix stopped working after a few minutes when Senza was started from the app. It now holds for
  the whole session and restores itself even if Senza crashes.
- A corrupt or hand-edited profile could push invalid values into the controller mapper during a live reload.
- Ending a session no longer tears down the system-wide tunnel's routing.
- Saved state is written atomically, so a crash can't leave `senza restore` without what it needs.
- Your Tailscale exit node is no longer hardcoded; set it with `senza config set exit-node <ip>`.
